# Mohaimin's Portfolio

A personal portfolio website built with **React 18**, **Rsbuild**, **TypeScript**, and **Tailwind CSS v3**.  
This site showcases projects, experience, and tries out new tech.

---

## Tech Stack

- **React 18** – for building modular UI components
- **Rsbuild** – fast, modern alternative to Vite/Webpack
- **TypeScript** – static typing for robust development
- **Tailwind CSS v3** – utility-first CSS for fast styling
- **Vercel** – for seamless deployment
